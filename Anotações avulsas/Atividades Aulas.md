1. Como faço pra acessar o desktop via cmd?
2. Qual o caminho para acessar a pasta users do disco local c:
3. Qual o caminho para alterar ad opções de desempenho do computador?

Respostas:
   
   1. O jeito mais simples é abrir o CMD e digitar **cd C:\Users\SeuNomeDeUsuario\Desktop** trocando o final pelo seu nome de usuário. Para confirmar que deu certo, digite **dir** e aperte Enter para ver a lista de arquivos da sua área de trabalho na tela.
2. O caminho mais simples para acessar a pasta de usuários no Prompt de Comando é digitar **cd C:\Users** e pressionar Enter. Para confirmar que deu certo e listar os usuários do computador, basta digitar **dir** e apertar Enter.
3. O jeito mais simples digitando na barra de pesquisa do Windows é pressionar a tecla **Windows**, digitar **Desempenho** e clicar na opção **Ajustar a aparência e o desempenho do Windows**. Para confirmar que deu certo, a janela _Opções de Desempenho_ vai se abrir diretamente na tela de configurações dos efeitos visuais.
