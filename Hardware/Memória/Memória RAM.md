**Memória RAM (Random Access Memory)**

A **RAM** é a memória principal do computador.

- **Leitura e Escrita:** Ela permite que o processador leia e escreva (modifique) dados em seu interior de forma extremamente rápida.
- **Volatilidade:** É uma memória **volátil**, ou seja, seu conteúdo é completamente apagado quando cortamos a alimentação elétrica (ao desligar o micro).
- **Função:** Armazena temporariamente o sistema operacional, os programas e os arquivos que estão abertos para serem processados. Se você abre um programa, ele é transferido do disco rígido para a RAM para que o processador possa executá-lo.
- **Estrutura física (DRAM):** A RAM principal é composta por circuitos de **memória dinâmica (DRAM)**, que guardam os bits em capacitores. Como os capacitores perdem carga, eles exigem um processo constante de recarga elétrica chamado **refresh**, o que limita a velocidade máxima dessa memória
